# AI Clinical Decision Support Assistant

## Overview

This project is an AI-powered healthcare assistant developed using Prompt Engineering, NLP, and FLAN-T5 fine-tuning.

The system analyzes patient symptoms and clinical features to generate structured healthcare reports containing:
- Possible cardiovascular conditions
- Confidence levels
- Medical reasoning
- Recommended tests
- Recommendations
- Precautions
- Disclaimer
